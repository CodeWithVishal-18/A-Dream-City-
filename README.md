## Responsive Skyline Illustration
A visually rich city skyline illustration built entirely with HTML and CSS.
This project focuses on advanced CSS concepts such as custom properties (CSS variables), gradients, layering, and responsive design—all without using images.

## ✨ Highlights

🌇 Pure CSS skyline (no image assets)

🎨 Custom color themes using CSS variables

🏙️ Foreground & background building layers

🌤️ Gradient sky with depth effect


## 🛠️ Tech Stack

HTML5

CSS3

## 🚀 Live Preview

Open index.html in your browser to view the skyline.
